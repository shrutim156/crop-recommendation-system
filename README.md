# 🌾 Crop Recommendation System

An AI/ML-powered web app that recommends the most suitable crop to grow based on soil nutrients (N, P, K) and environmental conditions (temperature, humidity, pH, rainfall) — with prediction confidence, top-3 alternatives, explainable AI, what-if analysis, and a full model performance dashboard.

> ⚠️ **Disclaimer:** Recommendations are generated by a machine learning model trained on historical data. They are a decision-support tool, not a guarantee — always validate with local agricultural experts and real soil testing before making planting decisions.

---

## ✨ Features

- **Crop prediction** with confidence score and top-3 ranked alternatives
- **Explainable AI** — SHAP-based (with an automatic fallback) per-feature contribution chart, plus a plain-language explanation of the recommendation
- **What-If analysis** — sweep any single input across its realistic range and watch the recommendation and confidence shift in real time
- **Crop comparison** — side-by-side ideal condition ranges for the top-3 recommended crops
- **Input validation** — warns when a value falls outside realistic agronomic ranges
- **Crop information library** — searchable/filterable reference for all 22 crops
- **Model performance dashboard** — accuracy/precision/recall/F1 comparison across 6 models, confusion matrix, and feature importance

## 🚀 Getting Started

### 1. Clone and set up an environment

```bash
git clone <your-repo-url>
cd crop-recommendation-system
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

### 2. Train the model

The dataset is already included at `data/Crop_recommendation.csv`, so you can train immediately:

```bash
python -m src.train_model
```

This trains and compares **Logistic Regression, Decision Tree, Random Forest, KNN, SVM, and XGBoost** (if installed), prints an accuracy/precision/recall/F1 comparison table, and saves the best-performing model to `models/crop_recommendation_model.joblib`.

### 3. (Optional) Inspect evaluation details

```bash
python -m src.evaluate_model
```

Prints the classification report and feature importances for the deployed model.

### 4. Launch the app

```bash
streamlit run app.py
```

Open the URL Streamlit prints (typically `http://localhost:8501`).

## 📊 About the Dataset

`data/Crop_recommendation.csv` is the widely-used public **Crop Recommendation Dataset** (2200 rows, 8 columns, 22 crop classes). Each row gives soil nutrient levels (N, P, K in kg/ha), temperature (°C), humidity (%), soil pH, and rainfall (mm), labeled with the crop best suited to those conditions. It contains no missing values or duplicate rows.

**Input features:** `N`, `P`, `K`, `temperature`, `humidity`, `ph`, `rainfall`
**Target:** `label` (crop name, one of 22 classes)

## 🧠 Model Selection

`src/train_model.py` trains six classifiers on an 80/20 stratified train/test split, evaluates each with Accuracy, Precision, Recall, and F1-score (weighted), and automatically deploys the one with the highest F1-score. In testing, **Random Forest** consistently comes out on top with **~99.5% accuracy** on held-out data, closely followed by XGBoost.

The saved artifact (`models/crop_recommendation_model.joblib`) bundles the fitted model, the label encoder, and the feature column order, so `src/prediction.py` and `app.py` never need to guess at preprocessing steps.

## 🔍 Explainability Notes

- If `shap` is installed, the app uses `TreeExplainer` (or the generic `Explainer` as a fallback) to compute real per-feature SHAP contributions for the predicted class.
- If SHAP is unavailable or errors on a given model, the app automatically falls back to a lightweight perturbation-based sensitivity estimate, so the "Why this crop?" panel always renders.
- The plain-language explanation text is a separate, rule-based summary (confidence level + a description of the recommended crop's typical growing conditions) — it is intentionally simple and transparent rather than trying to narrate SHAP values directly.
